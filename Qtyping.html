복구 아이콘을 누르면 양식 목록으로 돌아옵니다. 휴지통도 HTML 저장·JSON 백업에 포함됩니다.

이 파일에 담긴 양식과 다른 변경사항이 이 컴퓨터에 남아 있습니다.

입력 / 선택

양식 편집

다른 컴퓨터로 옮기기 전에는 위의 저장 아이콘을 누르세요.

1. 입력할 항목 만들기

2. 문서 틀 작성하기

항목 버튼을 누르거나 문서 틀에서 @를 입력해 항목을 찾으세요. ↑↓로 이동 · Enter/Tab으로 삽입 · Esc로 닫기

항목 이름을 바꾸면 문서 틀의 [항목 이름]도 함께 바뀝니다.

입력한 문서 내용은 파일·브라우저에 저장하지 않습니다. HTML 저장에는 양식 설정만 포함됩니다.
사용법 / 저장 방법
  1. 새 양식을 만들거나 작업 영역의 양식 이름 옆 양식 편집 버튼을 누릅니다.
  2. 주관식·객관식 항목과 선택지를 설정하고, 문서 틀에 [항목 이름]을 넣습니다. 항목 버튼을 누르거나 @ 뒤에 항목 이름 일부를 입력해 선택할 수 있습니다.
  3. 편집 완료 후 입력·체크하면 완성본이 바로 바뀝니다. 복사해서 사용하세요.
  4. 양식을 변경했다면 제목 옆의 저장 아이콘을 누릅니다. 처음에는 지금 열어둔 HTML 파일을 선택하고 브라우저의 쓰기 권한을 허용하세요. 이후에는 선택한 파일 자체에 저장합니다.
  5. 원본 저장은 Chrome / Edge에서 사용할 수 있습니다. 파일을 다시 열거나 쓰기 권한이 해제된 경우 파일 선택·권한 확인이 다시 필요할 수 있습니다.
  6. 저장한 HTML 파일을 Google Drive 등에 올려 보관하세요. 다른 컴퓨터에서 최신 파일을 내려받아 브라우저로 열면 양식까지 그대로 사용할 수 있습니다.
  7. 내보내기 아이콘은 설정만 JSON 파일로 저장합니다. 불러오기 아이콘으로 백업한 양식을 추가할 수 있습니다. 아이콘 위에 마우스를 올리면 기능 설명이 표시됩니다.
  8. 양식 목록의 이름 오른쪽에 있는 복제·휴지통 아이콘으로 양식을 복제하거나 휴지통으로 옮길 수 있습니다. 삭제한 양식은 목록 아래의 휴지통을 펼쳐 복구하세요. 삭제·복구 후에도 저장 아이콘을 눌러 파일에 반영합니다.
  9. 왼쪽 목록의 양식 이름을 위아래로 드래그하면 순서를 바꿀 수 있습니다. 이름에 키보드 초점을 두고 Alt+↑/↓로도 이동할 수 있습니다. 바꾼 순서는 저장 아이콘을 눌러 파일에 반영하세요.

로그인·설치·인터넷 연결 없이 동작합니다. Ctrl+S(또는 ⌘S)도 같은 파일에 저장합니다. 저장 전 탭을 닫거나 새로고침하면 브라우저의 나가기 확인창이 뜹니다. 머무르기를 선택한 뒤 저장하세요.
